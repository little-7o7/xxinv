# Shavkat / Shuhrat — персональные приглашения

Next.js App Router, TypeScript, React. Проект находится прямо в этой папке.

## Разработка

```sh
npm install
npm run dev
```

## Ссылки

- Главная `/` автоматически перенаправляет на `/ru/shavkat`.

- `/shavkat` → `/ru/shavkat`, `/shuhrat` → `/ru/shuhrat`. Без языка по умолчанию используется русский.
- `/ru/shavkat` и `/ru/shuhrat` — «Дорогой гость!», `/uz/shavkat` и `/uz/shuhrat` — «Hurmatli mehmon!». Имя в URL не добавляется.

- `/ru/shavkat/amir_aka` — приглашение от Shavkat на русском, обращение «Дорогой Amir Aka!».
- `/uz/shuhrat/amir_aka` — приглашение от Shuhrat на узбекском, обращение «Hurmatli Amir Aka!».
- Доступны оба языка для каждого юбиляра. Любое имя гостя можно передать последней частью ссылки; пробелы обозначаются `_`.
- Язык переключается с сохранением юбиляра и имени гостя. Переключателя юбиляров на странице нет.
- Старые ссылки `/ru/amir` и `/uz/amir_aka` перенаправляются на приглашение от Shavkat.
- Неверные языки, юбиляры и лишние сегменты возвращают 404.

## Фотографии и оформление

В `lib/invitations.ts` находятся независимые настройки Shavkat и Shuhrat: `name`, `photo`, `theme`.
Фотографии положите в `public/photos/` и укажите публичный путь: `/photos/shavkat.jpg`, `/photos/shuhrat.jpg`.
До добавления фотографий показываются подписанные заглушки.
Темы средней яркости: `sapphire` (сапфирово-голубой), `rose` (розовая медь), `jade` (нефрит). Переключатель на странице сохраняет выбор в браузере отдельно для каждого юбиляра. Общее оформление по умолчанию задаётся в конфигурации.

Внизу страницы есть генератор персональных ссылок. Он сохраняет выбранного юбиляра и язык.

Дата: 4 ноября. Ресторан «Самарканд», Самарканд. Время пока не указано. Ссылка на карту открывает поиск ресторана, точный адрес необходимо подтвердить.

## Галереи, прокрутка и музыка

- На каждой странице есть портреты обоих братьев; первым показан юбиляр из URL. Переключателя юбиляров нет.
- Одна фотография ресторана снаружи задаётся в `lib/restaurant.ts`. До добавления снимка видна подписанная заглушка фасада.
- Плавная прокрутка по разделам, индикатор чтения, появление блоков при скролле. При системной настройке уменьшения движения анимации отключены.
- Логотип прокручивает текущую страницу наверх без перехода и перезагрузки.
- `public/audio/celebration.wav` — оригинальная синтезированная инструментальная мелодия для приглашения (84 BPM, 3/4), без сторонних записей.
- Воспроизведение при входе запускается, если браузер разрешает autoplay со звуком. Если браузер блокирует автозапуск, музыка автоматически включается при первом нажатии на странице. Кнопка звука сохраняет явное управление включением и отключением. Приглашение всегда открывается сразу, без вступительного экрана. Музыка зациклена, громкость по умолчанию 32%.

## Праздничный фон

Три вечерние темы: сапфир, розовая медь и нефрит. Позади контента — мягкое свечение, золотые звёзды и фейерверки на canvas. Анимация приостанавливается в скрытой вкладке, учитывает prefers-reduced-motion и отключается кнопкой внизу слева.

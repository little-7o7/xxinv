# Xasan / Xusan — персональные приглашения

Next.js App Router, TypeScript, React. Проект находится прямо в этой папке.

## Разработка

```sh
npm install
npm run dev
```

## Ссылки

- `/ru/xasan/amir_aka` — приглашение от Xasan на русском, обращение «Дорогой Amir Aka!».
- `/uz/xusan/amir_aka` — приглашение от Xusan на узбекском, обращение «Hurmatli Amir Aka!».
- Доступны оба языка для каждого юбиляра. Любое имя гостя можно передать последней частью ссылки; пробелы обозначаются `_`.
- Язык и вкладка юбиляра переключаются с сохранением имени гостя.
- Старые ссылки `/ru/amir` и `/uz/amir_aka` перенаправляются на приглашение от Xasan.
- Неверные языки, юбиляры и лишние сегменты возвращают 404.

## Фотографии и оформление

В `lib/invitations.ts` находятся независимые настройки Xasan и Xusan: `name`, `photo`, `theme`.
Фотографии положите в `public/photos/` и укажите публичный путь: `/photos/xasan.jpg`, `/photos/xusan.jpg`.
До добавления фотографий показываются подписанные заглушки.
Темы: `emerald`, `ivory`, `black`. Переключатель на странице сохраняет выбор в браузере отдельно для каждого юбиляра. Общее оформление по умолчанию задаётся в конфигурации.

Внизу страницы есть генератор персональных ссылок. Он сохраняет выбранного юбиляра и язык.

Дата: 4 ноября. Ресторан «Самарканд», Самарканд. Время пока не указано. Ссылка на карту открывает поиск ресторана, точный адрес необходимо подтвердить.

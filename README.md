# Xasan / Xusan — персональные приглашения

Next.js App Router, TypeScript, React. Проект находится прямо в этой папке.

## Разработка

```sh
npm install
npm run dev
```

## Ссылки

- Главная `/` автоматически перенаправляет на `/ru/xasan`.

- `/xasan` → `/ru/xasan`, `/xusan` → `/ru/xusan`. Без языка по умолчанию используется русский.
- `/ru/xasan` и `/ru/xusan` — «Дорогой гость!», `/uz/xasan` и `/uz/xusan` — «Hurmatli mehmon!». Имя в URL не добавляется.

- `/ru/xasan/amir_aka` — приглашение от Xasan на русском, обращение «Дорогой Amir Aka!».
- `/uz/xusan/amir_aka` — приглашение от Xusan на узбекском, обращение «Hurmatli Amir Aka!».
- Доступны оба языка для каждого юбиляра. Любое имя гостя можно передать последней частью ссылки; пробелы обозначаются `_`.
- Язык переключается с сохранением юбиляра и имени гостя. Переключателя юбиляров на странице нет.
- Старые ссылки `/ru/amir` и `/uz/amir_aka` перенаправляются на приглашение от Xasan.
- Неверные языки, юбиляры и лишние сегменты возвращают 404.

## Фотографии и оформление

В `lib/invitations.ts` находятся независимые настройки Xasan и Xusan: `name`, `photo`, `theme`.
Фотографии положите в `public/photos/` и укажите публичный путь: `/photos/xasan.jpg`, `/photos/xusan.jpg`.
До добавления фотографий показываются подписанные заглушки.
Темы: `emerald`, `ivory`, `black`. Переключатель на странице сохраняет выбор в браузере отдельно для каждого юбиляра. Общее оформление по умолчанию задаётся в конфигурации.

Внизу страницы есть генератор персональных ссылок. Он сохраняет выбранного юбиляра и язык.

Дата: 4 ноября. Ресторан «Самарканд», Самарканд. Время пока не указано. Ссылка на карту открывает поиск ресторана, точный адрес необходимо подтвердить.

## Галереи, прокрутка и музыка

- На каждой странице есть портреты обоих братьев; первым показан юбиляр из URL. Переключателя юбиляров нет.
- Одна фотография ресторана снаружи задаётся в `lib/restaurant.ts`. До добавления снимка видна подписанная заглушка фасада.
- Плавная прокрутка по разделам, индикатор чтения, появление блоков при скролле. При системной настройке уменьшения движения анимации отключены.
- Логотип прокручивает текущую страницу наверх без перехода и перезагрузки.
- `public/audio/celebration.wav` — оригинальная синтезированная инструментальная мелодия для приглашения (84 BPM, 3/4), без сторонних записей.
- Воспроизведение при входе запускается, если браузер разрешает autoplay со звуком. В остальных случаях кнопка «Открыть приглашение» запускает музыку по нажатию. Есть вход без музыки и постоянная кнопка управления звуком. Музыка зациклена, громкость по умолчанию 32%.
